# Changelog

All notable changes to Goosse Tooltip are documented here.

## [1.0] – 2026-11-03

### Added

- `goosseTooltip.version` — readable module version
- Initial release: styled Bootstrap 5.3 tooltips with correctly coloured arrows
- Tooltip colour variants: primary, secondary, info, success, warning
- Arrow colour matched per `data-popper-placement`
- Auto-initialisation of `[data-bs-toggle="tooltip"]` on `DOMContentLoaded`
- README: usage examples per variant and `initGoosseTooltips()` pattern for AJAX re-initialisation

### Fixed

- README: removed leftover draft text and empty code blocks
